# test/pr38

PR #38（`apps/web`: Pages フロントエンド一式 F1〜F10 全画面）の、PR本文「非エンジニア向け
ユーザーテスト」欄の手順を再現するPlaywright自動化スクリプトです。

対象は開発サーバー（`http://localhost:5173`、apps/apiは `http://localhost:8787`）のみです。
本番・ステージング環境には実行しません。

## 事前準備・実行方法

Playwrightの `webServer` 設定（`test/pr38/playwright.config.ts`）により、テスト実行時に
以下が自動起動します（既に起動済みのサーバーがある場合はそれを再利用します）。

1. apps/api（`wrangler dev`、ポート8787）。起動前にD1ローカルDBへ `db/schema.sql` を適用します
   （`CREATE TABLE IF NOT EXISTS` のため複数回実行しても安全です）。
2. apps/web（Vite dev server、ポート5173）。`apps/web/vite.config.ts` のプロキシ設定により、
   `/api` 配下のリクエストは同一オリジンで apps/api へ転送されます（Cookieセッションが
   ブラウザ・開発サーバー間で問題なく往復します）。

実行:

```bash
npx playwright test --config=test/pr38/playwright.config.ts
```

テスト完了後、Playwrightが自身で起動したサーバーは自動的に停止します
（既に起動済みのサーバーを再利用した場合は停止しません）。

## 手順とアサーションの対応

PR本文の「非エンジニア向けユーザーテスト」欄の番号と、`test/pr38/pr38.spec.ts` 内の
`test.step` を1対1で対応させています。

| PR本文の手順 | 確認内容 | スクリプト内の対応（`test.step`） |
|---|---|---|
| 1. トップページを開く | 「サンプル組織を読み込む」ボタンが表示される | 手順1 |
| 2. 「サンプル組織を読み込む」を押す | 「次元◯件・ポリシー◯件・タスク◯件を読み込みました。」の通知が表示される | 手順2 |
| 3. 「タスク管理」メニューを押す | タスクの一覧が表示される（一覧テーブルの行が1件以上ある） | 手順3 |
| 4. 一覧の行から「割当・根拠を見る」を押す | 「割当・根拠」の見出し、「採用モデル」「得点内訳」「次点候補」の項目が表示される | 手順4 |
| 5. 「ポリシー管理」メニューを押す | ポリシーの一覧が表示され、「ポリシー名」「特異度」「優先度」「状態」の列が確認できる | 手順5 |

手順4は、サンプル読込直後の一覧で先頭の行が未割当（採用モデルなし）だった場合に備え、
「得点内訳」が表示される行が見つかるまで他の行を順に試す実装にしています
（`得点内訳` は `apps/web/src/pages/TaskAssignmentDetailPage.tsx` の実装上、採用モデルが
決まった場合のみ表示されるセクションのため）。
